Publica y organiza tu web

Crea tus entradas de Prompts, Proyectos y Herramientas docentes con portada, carrusel, enlaces y documentos. Se guardan directamente en tu repositorio.

Es una clave de acceso de GitHub, no tu contraseña. Solo necesitas permiso Contents: Read and write para el repositorio tecnologiapuntes/tecno.

¿Cómo consigo el token? (solo la primera vez)
  1. Entra en GitHub → Nuevo token de acceso limitado.
  2. Selecciona propietario de tu cuenta y Only select repositories → tecno.
  3. En Repository permissions, permite Contents → Read and write.
  4. Establece una caducidad adecuada; genera el token y cópialo.
  5. Pégalo arriba. Nunca compartas el token ni lo añadas a GitHub como archivo.
🔒 El token se mantiene solo en la memoria de esta pestaña: no se guarda en tu web, en archivos ni en el navegador. Al recargar la página tendrás que introducirlo de nuevo.

NAVEGACIÓN

Menús y apartados

Organiza hasta tres niveles: apartados, subapartados y sub-subapartados. Los cambios aparecerán en la barra superior y en el botón «Menú», también en Cuaderno de Séneca y Videotutoriales IA.

Editar apartado

Puedes poner un elemento dentro de otro subapartado para crear un tercer nivel. La ubicación es editable; no se pierden sus publicaciones. Para crear una categoría nueva, elige «Mostrar publicaciones» y escribe su nombre. Después podrás seleccionarla al crear un post. Para enlaces externos utiliza https://. Para páginas propias utiliza el nombre del archivo, por ejemplo cuaderno-seneca.html.

Los cambios no se publican hasta pulsar «Guardar menú en GitHub». No se modificarán tus publicaciones ni el archivo de vídeos de Séneca.

Las publicaciones nuevas se guardan en assets/cms-posts.json, sin modificar los 24 posts originales de assets/posts.js. Los cambios quedan registrados en GitHub y no sobrescriben los vídeos de Séneca. Los menús se editan desde la pestaña «Menús y apartados».
