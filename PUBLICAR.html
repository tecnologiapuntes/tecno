Publicar un nuevo recurso

La web se publica desde tu repositorio de GitHub. Solo las cuentas con permiso de escritura en ese repositorio pueden modificar lo que ven tus visitantes.

1. Prepara la entrada

Este formulario genera un archivo actualizado. No publica ni envía datos a ningún servidor.

2. Sube los cambios a GitHub

  1. Entra en GitHub con tu usuario y contraseña.
  2. Abre el repositorio de esta web y entra en la carpeta assets.
  3. Sube el archivo posts.js que has descargado, sustituyendo al anterior.
  4. Si hay imágenes nuevas, súbelas a assets/posts con los mismos nombres que has indicado.
  5. Confirma los cambios con Commit changes. GitHub Pages actualizará la web.

Conserva una copia del archivo antes de sustituirlo. Este formulario parte del contenido que tiene la web cuando abres la página. No compartas permisos de escritura si quieres ser la única persona que publique.

El acceso con usuario y contraseña propio del editor de Sites pertenece a la versión con servidor. No funciona en GitHub Pages. Aquí la publicación se protege con tu cuenta de GitHub.
